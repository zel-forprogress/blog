1. deepseek-v4本身是一个语言模型，它不具备图片识别能力，因此当我们在通过API调用来使用它的时候，它识别不了我们上传的图片。网页版可以具有图片识别的能力，是因为它使用了另外具有图片识别能力的模型，然后将该图片中的内容以文字的形式发给deepseek-v4模型。

2. 在进行模型调试的时候，我们不可或缺的会遇到这几个比较有代表性的参数：temperature：其值影响模型的回答是否具有变化性；top-K与top-P：我们知道模型的回答是根据可能性来回答的，下一个词在所有可选词中的可能性排名是靠前的，而这两个参数的作用就是调整模型可选词的范围，top-k是指模型只能在最有可能的前k个词中来选择；而top-P与top-K的意思差不多，top-p是指模型按词的得分从高到低往下累加，一直加到总分达到 P% 时停止，划一条线，线内的词都能入选。Frequency Penalty（惩罚频率），控制模型避免重复啰嗦，它的值为正时，对已经使用过的词，再次使用过多可能性降低，惩罚改词，当它的值为负时，对已经使用过的词来说，模型鼓励再次使用他们。

3. SQLAIchemy是一个ORM（objection relation mapping 对象关系映射）框架，所谓的ORM框架就是让我直接使用通过该框架在编程语言中定义的类来直接操作数据库表，而不是通过SQL。

4. CCSwitch中本地路由功能是这样的，对于某些agent它只能使用特定的模型，比如Codex中没有配置第三方模型的入口，只能使用官方的模型，因此这时本地模型就起作用了，它只对第三方模型起作用，它会将codex中请求转发到本地路由，然后由CCSwitch以第三方模型兼容的请求方式请求它，这样我们就可以在codex中使用第三方模型了。但是在设置完之后可能会出错，“502 Bad Gateway: Unknown error, url: http://127.0.0.1:15721/v1/responses”
   正常情况应该是这样的：
   
   
   代码
   
   
   ```plaintext
   Codex CLI  →  直接请求  →  localhost:15721 (CCSwitch 本地路由)  →  Deepseek API
   ```
   
   
   但实际发生的是这样（reqwest 的 bug）：
   
   
   代码
   
   
   ```plaintext
   Codex CLI  →  请求发给了  →  localhost:9674 (CCSwitch 系统代理) ->代理端心想："让我帮你转发 localhost:15721..."丢掉了必要的信息             ↓            代理端心想："让我帮你转发 localhost:15721..."                  ↓            代理端自己转发给自己？懵了  →  502
   ```
   
   
   Codex 的配置文件里写的是 `base_url = "``http://127.0.0.1:15721/v1``"`，意思是让 Codex 直接请求本地路由。但由于 Rust 的 `reqwest` 库过于"听话"地遵守 Windows 系统代理设置，把本该直连 `15721` 的请求，先丢给了 `9674` 代理端口：
   
   
   1. 9674 收到请求，拆开一看："哦你要去 `127.0.0.1:15721`"
   
   
   6. 9674 说："那我也去访问 15721 帮你把结果拿回来"
   
   
   7. 9674 就去访问 `http://127.0.0.1:15721/v1/responses`...
   
   
   8. 但是转发过程中丢掉了必要信息，导致失败。

所以这不是 Codex 刻意走代理转发，而是 HTTP 库自作主张多绕了一圈导致的问题。`NO_PROXY` 就是告诉它："本地地址别走代理，按配置文件写的直连就行。"

9. 本地路由接管Codex配置后，Codex其实并不知道自己在用DeepSeek。
   它的工作原理是：
   
   
   1. CCSwitch修改了Codex的配置文件（`~/.codex/config.toml`），将`base_url`强制指向本地地址`http://127.0.0.1:15721/v1`。
   
   
   11. 当Codex发出请求时，它依然以为自己是在调用`https://api.openai.com/v1/responses`。
   
   
   12. 但实际上，请求已经被劫持到了CCSwitch本地，由CCSwitch做协议转换。
   
   
   13. 因此，Codex“自始至终都不知道”背后换了模型，它收到的回答格式和自己预期的完全一致。
