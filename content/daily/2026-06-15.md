2. MCP Server 到底是什么？我的理解是服务官方专门提供给agent的接口，让其获取信息或者进行直接通过这些接口进行一些操作。

4. Hermes agent最大的特点是其具有自我进化的能力，所谓的进化是指其拥有对知识、聊天记录进行自我总结的能力。也就是说你们每一次对话，它都会内化成自己的东西，因此每一次新对话，它都是进化后的agent。

5. 命令解析：`irm ... | iex` ,  这里的irm 是 Invoke-RestMethod的缩写 iex是 Invoke-Expression的意思，这个命令的整体意思是“从网上下载一个安装**脚本**，并立即在您的电脑上运行它“，例如：irm https://hermes-agent.nousresearch.com/install.ps1 | iex 就是为 Windows 系统安装名为 Hermes Agent 的 AI 智能体
